# Hito 1 TrackFlow

Sitio web público de TrackFlow con landing corporativa y formulario de solicitud comercial.

## Archivos principales

- CONTEXT.md
- index.html
- application.html
- validation.js

## Stack

- HTML5 semántico
- Tailwind CSS v4 por CDN
- JavaScript vanilla
- Sin CSS personalizado

## Ejecución

```bash
pip3 install flask && python3 server.py
```

Abrir:

- http://127.0.0.1:5000/index.html
- http://127.0.0.1:5000/application.html
